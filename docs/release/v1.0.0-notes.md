# Go Sensei v1.0.0 Release Notes

Draft these notes with the release candidate, then update the commit SHA, deployment URL, and smoke-test results in the final `v1.0.0` release PR.

## Learner-Facing Changes

Go Sensei now guides a new learner through a complete beginner loop instead of dropping them into an open board with a chat box. The first-run experience can start on a guided 9x9 game with one visible objective, board target markers, and local coaching for common beginner questions.

The learning path now connects guided play, lessons, engine-backed problems, spaced review, concept mastery, and progress feedback into one recommended path. A beginner can ask what to do next, practice the relevant concept, review weak spots, and return to guided play without losing the thread.

AI tutoring is more useful when networked model calls are unavailable or when the learner asks common board-specific questions. Local coaching routes answer many "why", "what next", cut, capture, connection, candidate move, and study-plan questions directly from current board and progress state.

The app also has stronger release discipline: CI runs the same release gate documented for local verification, and production GitHub OAuth must use a dedicated `GITHUB_OAUTH_CLIENT_ID` instead of silently falling back to the development client.

## Setup Requirements

- Node.js 18 or newer.
- A GitHub account with GitHub Copilot access for AI-backed tutoring.
- For production deploys, a dedicated GitHub OAuth App with Device Flow enabled.
- `GITHUB_OAUTH_CLIENT_ID` set in the production environment.

Local development can still use the bundled Copilot OAuth client fallback, but that fallback is not release configuration.

## Known Limitations

- Go Sensei requires GitHub Copilot access for the full AI tutor experience.
- Learner progress is local to the browser storage model; cross-device sync is not part of `v1.0.0`.
- Production auth setup is required before release. The development OAuth fallback must not be used for a production deployment.
- The 1.0 learning loop is beginner-focused. Intermediate and advanced teaching modes exist, but the most complete guided path is for new learners.
- The release should not be tagged while the candidate PR is draft, while `package.json` is still pre-1.0, or before production smoke evidence is recorded.
